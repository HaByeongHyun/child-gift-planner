## 기록 정책
신규 기록은 비어 있다. 예시는 메모리에서만 열고 내 기록으로 되돌아간다. v1 저장 원본은 읽기만 하며 v2에 자동 이관하지 않는다. 사용자가 확인 후 가져오면 기존 증여 여부 X/O는 계좌 기준 오판 가능성이 있어 미확인으로 전환한다. 기존 원본은 삭제하지 않는다. 예시 모드에서는 v2도 변경하지 않는다. 저장 실패 안내를 표시한다.

## 미확인
정기금 최대 평가액, 실제 과거 이력에 따른 공제 잔여액, 날짜 경계일 세무 판단, 미래 전체 공휴일, 실제 세액은 제공하지 않는다. 세뱃돈·용돈은 보관 계좌만으로 비과세 여부를 자동 판단하지 않는다.
